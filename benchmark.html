Agentic benchmark on real dental X-rays

Each task is one panoramic radiograph. The agent must find every periapical lesion, draw a box around it, and grade it 3, 4 or 5 on the Periapical Index. It works in a sandbox with no network. It can run Python, crop and enhance the film, and look at the result, for up to 50 turns. A deterministic grader matches its boxes one-to-one to the dentists' boxes (IoU ≥ 0.3) and scores lesion F1 and exact-grade F1. Extra boxes count against the answer, so boxing everything scores about zero.

Only complete runs are ranked. A film that reached the 50-turn limit without an answer scores 0. A failed or missing film is not scored as zero, so a run with any of them stays unranked.

Post-training gains

A separate study, not an agent comparison. Inkling-Small is fine-tuned, then trained with reinforcement learning on 500 held-out films. It answers each film in six tiled calls (3×2 tiles at 2× zoom), without tools.

How scoring works

Reward is ½ lesion F1 plus ½ graded F1. A film passes only at reward 1.

Scoring

Find
Every lesion. A miss and a false alarm both cost.
Box
One-to-one at IoU ≥ 0.3. Extra boxes count against the answer.
Grade
PAI 3, 4 or 5, exact. A ±1 tolerance would make PAI 4 always right.
Ceiling
Two dentists scoring each other reach reward 0.83 and pass 61% (59 films read twice, not the test set).

Protocol

Films
First 200 test films, no shuffle, one scored result per film.
Splits
Per film. Look-alike films stay in the same split.
Agents
Codex 0.147.0 for GPT-6 Astra. Claude Code 2.1.280 for the others. Up to 50 turns.
Re-runs
A film that ends in a sandbox, tunnel or harness fault is run again. A film that reaches the turn limit keeps its score.
Traces
Public messages, tools, returned thinking and images. Read them.

The other environment, panoramic-dicom-ingest, asks for one exact lesion table from a DICOM archive. It has three levels, and reward is exactness.
